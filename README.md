# ActualPay UK project package

- `production/` is the static website directory intended for GitHub Pages deployment.
- `project-docs/` contains audits, reports and owner checklist; do not publish it as the website root.
- `source-archive/` preserves the original hero video source; do not publish it.

Deploy the contents of `production/` as the GitHub Pages root. Review `project-docs/ACTUALPAY_FINAL_QA_REPORT.md` and complete `project-docs/ACTUALPAY_OWNER_APPROVAL_CHECKLIST.md` before launch.
